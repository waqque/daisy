# Технологическая карта (рецепт приготовления)

## Наименование блюда: Блинчики классические (порция 2 шт.)

### 1. Характеристики блюда
* **Категория:** Готовая продукция / Завтраки
* **Выход готового блюда:** 160 г
* **Упаковка:** Контейнер пищевой картонный (15 г)
* **Нормативный документ:** ТТК № 01-2026

### 3. Технологический процесс приготовления

#### Подготовка полуфабриката (Тесто блинное):
1. В емкость разбить куриное яйцо, добавить сахар-песок и соль.
2. Взбить венчиком до однородной консистенции.
3. Влить половину объема теплого молока (50 г), непрерывно помешивая.
4. Постепенно ввести просеянную муку, замешивая однородное тесто без комочков.
5. Добавить оставшуюся часть молока и растительное масло. Тщательно перемешать.

#### Тепловая обработка:
1. Разогреть блинную сковороду до температуры 180°C.
2. Равномерно налить тесто тонким слоем.
3. Выпекать блинчики с двух сторон до золотистого цвета (по 1–1.5 мин с каждой стороны).

---

### 4. Складской и производственный регламент списания
* **Списание сырья:** Выполняется документом `СписаниеНоменклатуры` по нормативам спецификации (режим: *С блокировкой при нехватке*).
* **Оприходование готового блюда:** Фиксируется операцией `ВыпускПродукции` на баланс раздачи.
