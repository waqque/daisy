# Описание доменов и сущностей системы сети ресторанов «Ромашка»

## 1. Организационная структура и инфраструктура

| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **Организация** | Головное юридическое лицо сети ресторанов (`ООО Ромашка`). | Включает в себя `Ресторан` и `ПроизводственныйЦех`; выступает стороной во взаиморасчетах с `Контрагент`. |
| **Ресторан** | Обособленный филиал сети питания (режим 10:00–22:00; форматы: доставка, зал или гибрид). | Входит в состав `Организация`; содержит `Помещение`, `Склад`, штат `Сотрудник`; принимает `ЗаказНаДоставку`. |
| **ПроизводственныйЦех** | Централизованное круглосуточное подразделение для приготовления заготовок и спецхранения сырья. | Входит в состав `Организация`; содержит холодильные `Помещение` и `Склад`; выполняет `ЗаказНаПроизводство`. |
| **Помещение** | Физическая изолированная зона филиала или цеха (кухня, зал, холодильная камера, склад). | Привязано к объекту `Ресторан` или `ПроизводственныйЦех`; строго связано со `Склад` (отношение 1-к-1). |

## 2. Складской учет

| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **ГруппаНоменклатуры** | Иерархическая категория классификации позиций учета. Блокируется от удаления при наличии записей. | Включает позиции `Номенклатура`; служит фильтром для проведения частичной `Инвентаризация`. |
| **Номенклатура** | Учетная единица: сырье, заготовки, блюда, тара/упаковка. Защищена от удаления. | Входит в `ГруппаНоменклатуры`; ссылается на `ЕдиницаИзмерения`; входит в `ОстатокНоменклатуры`, `ТехнологическаяКарта`. |
| **ЕдиницаИзмерения** | Общероссийский или внутренний классификатор мер (кг, л, шт, порция). | Закрепляется за позицией `Номенклатура`; используется в складских и производственных строках. |
| **Склад** | Точка материально-ответственного хранения запасов. | Жестко привязан к объекту `Помещение`; хранит `ОстатокНоменклатуры`; объект `Инвентаризация`. |
| **ОстатокНоменклатуры** | Регистр текущего количественного остатка позиции на складе. | Связывает `Склад` и `Номенклатура`; изменяется через `СписаниеНоменклатуры` и `ВыпускПродукции`. |
| **СписаниеНоменклатуры** | Документ списания запасов («с блокировкой при нехватке» или «под сальдо»). | Привязан к `Склад` и `Номенклатура`; обязательно фиксирует ответственного `Сотрудник`. |
| **Инвентаризация** | Документ сверки фактических остатков (ежемесячная плановая или частичная по группе). | Проводится в разрезе `Склад`; может фильтроваться по `ГруппаНоменклатуры`; фиксирует `Сотрудник`. |
| **СтрокаИнвентаризации** | Табличная строка сопоставления учетного и фактического количества. | Входит в состав документа `Инвентаризация`; ссылается на конкретную позицию `Номенклатура`. |

## 3. Производственный учет

| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **ТехнологическаяКарта** | Нормативная рецептура; может быть составной (включать вложенные техкарты). | Определяет выпуск для `Номенклатура`; включает `СтрокаТехкарты` и дочерние `ТехнологическаяКарта`. |
| **СтрокаТехкарты** | Норма расхода сырья, полуфабриката или тары на единицу выхода. | Входит в `ТехнологическаяКарта`; ссылается на расходуемую `Номенклатура` или дочернюю карту. |
| **ПриготовлениеПолуфабриката** | Операция изготовления заготовки по рецептуре с отражением расхода компонентов. | Использует `ТехнологическаяКарта`; оформляет `СписаниеНоменклатуры`; фиксирует `Сотрудник`. |
| **ПриготовлениеБлюда** | Операция изготовления готового блюда для зала или доставки. | Выполняется по `ТехнологическаяКарта`; инициирует расход сырья со `Склад`; фиксирует `Сотрудник`. |
| **ВыпускПродукции** | Первичный документ оприходования готовых блюд/заготовок на баланс склада. | Связан с `ЗаказНаПроизводство`, `Склад`, позицией `Номенклатура` и ответственным `Сотрудник`. |
| **УтилизацияПродукции** | Документ списания брака, испорченного сырья или просроченных блюд. | Оформляет выбытие `Номенклатура` со `Склад`; фиксирует причину и ответственного `Сотрудник`. |

## 4. Сопровождение курьерской службы

| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **РайонДоставки** | Географическая зона обслуживания с фиксированным тарифом стоимости. | Закреплен за ближайшим `Ресторан`; передается в параметры `ЗаказНаДоставку`. |
| **МенюДляДоставки** | Специализированный прейскурант блюд, доступных для заказа курьером. | Состоит из позиций `ПозицияМенюДоставки`; используется при оформлении заказов. |
| **ПозицияМенюДоставки** | Комплект для доставки, объединяющий готовое блюдо и обязательную упаковку. | Входит в `МенюДляДоставки`; включает `Номенклатура`-блюдо и `Номенклатура`-тару. |
| **МаршрутныйЛист** | Наряд-рейс курьера на доставку скомплектованных заказов клиентам. | Закрепляется за `Сотрудник` (курьер); объединяет один или несколько `ЗаказНаДоставку`. |

## 5. Финансовый учет и взаиморасчеты

| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **ГруппаКонтрагентов** | Категория контрагентов (поставщики мяса/молока, арендодатели, клиенты). | Группирует объекты `Контрагент`. |
| **Контрагент** | Юридическое или физическое лицо, с которым ведутся взаиморасчеты. | Входит в `ГруппаКонтрагентов`; контрагент для `Организация`; фигурирует в платежах и заказах. |
| **ТипОплаты** | Метод финансового расчета (`наличные`, `банковский перевод` и прочее). | Указывается в документах `Поступление` и `Списание`. |
| **Поступление** | Документ учета прихода денежных средств (оплата заказов клиентами). | Связан с `Контрагент`, `ТипОплаты`, `ЗаказНаДоставку`; фиксирует ответственного `Сотрудник`. |
| **Списание** | Документ учета расхода денежных средств (расчеты с поставщиками и др.). | Связан с `Контрагент`, `ТипОплаты`; фиксирует ответственного `Сотрудник`. |

## 6. Учет персонала

| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **КатегорияСотрудника** | Направление: `Производство`, `Обслуживание` или `Управление`. | Закрепляется за `Сотрудник`; определяет допустимые правила для `ГрафикРабот`. |
| **ТарифнаяСтавка** | Нормативная ставка оплаты труда (почасовая или оклад). | Назначается для `Сотрудник`; база для расчета базовой оплаты и двойного тарифа за переработки. |
| **ГрафикРабот** | Плановый регламент: посменно (смены ≤ 8 ч) для производства; пятидневка по 8 ч для остальных. | Назначается для `Сотрудник`; формируется из плановых интервалов `Смена`. |
| **Смена** | Плановый интервал рабочего времени (плановое начало, конец, норма часов). | Входит в `ГрафикРабот`; нормативная база для сопоставления с `ФактОтработанногоВремени`. |
| **Сотрудник** | Физическое лицо, работающее в сети. Удаление блокируется при наличии операций. | Входит в `КатегорияСотрудника`; привязан к объекту сети, `ГрафикРабот`, `ТарифнаяСтавка`. |
| **ФактОтработанногоВремени** | Фактическая отметка начала и окончания смены. Фиксирует переработку сверх нормы. | Ссылается на `Сотрудник` и плановую `Смена`; передает часы переработки для расчета с `ТарифнаяСтавка`. |

## 7. Оперативный учет и контроль

| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **ЗаказНаДоставку** | Заказ клиента, адресуемый ближайшему ресторану, работающему на доставку. | Связан с `Ресторан`, `РайонДоставки`, `ПозицияМенюДоставки`, `Сотрудник` и `Поступление`. |
| **ЗаказНаПополнениеСклада** | Заявка администратора ресторана в цех на поставку заготовок и сырья к утру. | Направляется из `Ресторан` в `ПроизводственныйЦех`; содержит строки позиций `Номенклатура`. |
| **ЗаказНаПроизводство** | Оперативный наряд цеху или кухне на выпуск партий полуфабрикатов и блюд. | Формируется на основе заявок `ЗаказНаПополнениеСклада`; закрывается через `ВыпускПродукции`. |
| **ЖурналАудита** | Сквозной системный аудит изменений данных для контроля ответственности персонала. | Фиксирует идентификатор сущности, тип события, время и ответственного `Сотрудник`. |
